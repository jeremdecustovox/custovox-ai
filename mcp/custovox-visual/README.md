# custovox-visual

Visual customer intelligence MCP server.

## What it does
Analyzes customer-submitted images and detects quality issues automatically.

## Use cases
- Hotel room photo analysis (TripAdvisor complaints)
- Product return photo classification
- Retail shelf monitoring
- SAV ticket image triage

## What it returns
- Image description
- Detected issue type
- Severity (none / low / medium / high)
- Suggested action

## Installation
pip install custovox-visual
